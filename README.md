# 어항멍

폰 속에 물고기 한 마리가 삽니다. 폰을 기울이면 물이 출렁이고, 물 위를 톡 치면 먹이가, 물속을 톡 치면 물고기가 다가옵니다.

설치 없이 브라우저에서 열리고, 홈 화면에 추가하면 앱처럼 전체 화면으로, 인터넷 없이도 열립니다(PWA).

## 기능

- **물리 출렁임**: 기울기 센서로 중력 방향을 읽어 얕은 물 방정식으로 수면을 계산합니다. 세게 흔들면 물방울이 튀어 유리에 맺힙니다.
- **물고기 한 마리**: 먹이 먹기, 다가와 바라보기, 하품, 딸꾹질, 기포 쫓기, 밤에는 잠자기. 먹이를 먹고 날이 지날수록 조금씩 자랍니다.
- **분위기**: 실제 시각에 맞춘 하루의 빛(새벽·낮·노을·밤), 비 오는 창, 로파이 필터, 가끔 찾아오는 달팽이·낙엽·별똥별
- **물소리**: 합성 물소리와 빗소리(첫 터치 후 켜기)
- **저장**: 이름, 함께한 날, 친밀도, 설정은 기기 안(localStorage)에만 저장합니다.
- **배터리 절약**: 초당 30장만 그리는 모드

## 파일 구성

```
index.html            화면 뼈대
css/app.css           스타일
js/app.js             물리·물고기·그리기·UI 전부 (의존성 없음)
sw.js                 서비스워커 (오프라인 저장)
manifest.webmanifest  설치 정보
privacy.html          개인정보 처리방침
fonts/                고운돋움 (KS X 1001 한글 2,350자 부분집합, OFL)
icons/                앱 아이콘, 파비콘, 공유 이미지
scripts/smoke.mjs     Playwright 스모크 테스트
```

빌드 단계가 없습니다. 저장소 루트를 그대로 정적 호스팅하면 됩니다.

## 로컬에서 실행

```sh
python3 -m http.server 8765
# http://localhost:8765 접속
```

서비스워커는 `https` 또는 `localhost`에서만 동작합니다. 폰으로 센서를 시험하려면 배포 주소(https)로 열어야 합니다.

## 테스트

```sh
npm install
npm test            # 로컬 서버를 띄운 상태에서 실행
```

확인 항목: 콘솔 오류 없음, 어항 렌더링, 패널·이름·설정 저장, 함께한 날 계산, 서비스워커 활성화, 오프라인 재실행, 글꼴 로드.

## 배포 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 저장
3. 1~2분 뒤 `https://420brm.github.io/eohangmeong/` 에서 열립니다.

## 새 버전 내보내기

파일을 고친 뒤 **`sw.js`의 `VERSION`과 `index.html`의 `#ver` 표시를 함께 올립니다.** 서비스워커는 저장본을 먼저 보여주고 뒤에서 새 파일을 받으므로, 사용자는 다음 실행부터 새 버전을 봅니다.
