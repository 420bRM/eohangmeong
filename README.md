# 어항멍

폰을 기울이면 물이 출렁이는 작은 어항입니다. 먹이를 주고 유리를 닦아 주면 진주를 받고, 진주로 친구를 들이고 어항을 꾸밉니다. 물고기는 아프거나 죽지 않습니다. 광고가 없고, 인터넷 없이도 열립니다.

설치 없이 브라우저에서 열리고, 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다(PWA).

## 기능

**어항**
- 기울기 센서로 중력 방향을 읽어 얕은 물 방정식으로 수면을 계산합니다. 세게 흔들면 물방울이 튀어 유리에 맺힙니다.
- 실제 시각에 맞춘 하루의 빛(새벽·낮·노을·밤), 비 오는 창, 가끔 찾아오는 달팽이·낙엽·별똥별
- 창밖 풍경 5가지: 도시의 창, 숲속 창가(반딧불이), 바닷가 창, 작은 카페, 우주 정거장
- 두 손가락으로 확대·축소, 데스크톱은 휠

**생물 11종**
- 물고기: 금붕어, 구피, 네온테트라(무리 지어 다님), 블랙 금붕어, 베타, 엔젤피시
- 친구: 체리새우·달팽이(유리 이끼를 먹음), 물개구리·거북이(수면으로 숨 쉬러 감), 우파루파(바닥을 좋아함)
- 먹이 먹기, 다가와 바라보기, 하품, 딸꾹질, 기포 쫓기, 밤에는 잠자기. 톡 치면 쓰다듬기
- 먹고 날이 지날수록 자라고, 다 자란 같은 종이 둘 이상이면 가끔 새끼가 태어납니다.

**돌봄과 진주**
- 포만도: 하루 남짓이면 바닥나므로 하루 한 번 먹이를 줍니다. 배불리 먹이면 진주 60
- 청결도: 유리에 이끼가 낍니다. 손가락으로 문질러 닦으면 진주 100
- 출석 진주 30, 7일 연속 150, 업적 25가지(함께한 1000일까지)
- 상점: 생물, 장식 8종(수초 3종, 마리모, 강돌, 유목, 동굴, 진주 조개), 바닥 3종, 창밖 풍경, 도구(자동 먹이통, 이끼 청소기, 어항 추가)
- 분양: 자란 만큼 진주를 돌려받습니다.

**어항 여러 개와 꾸미기**
- 어항은 3개까지, 생물과 장식은 어항마다 따로입니다. 생물을 다른 어항으로 옮길 수 있습니다.
- 장식은 끌어서 옮기고, 앞뒤를 바꾸고, 보관함에 넣었다 다른 어항에 놓습니다. 마리모는 기울인 쪽으로 굴러갑니다.

**그 밖에**
- 시계 모드: 날짜·시각·배터리를 크게 보여 줍니다. 책상이나 머리맡에 세워 두는 용도입니다.
- 배경음악 3가지(오르골, 로파이, 잔잔한)를 WebAudio로 만들어 냅니다. 음원 파일이 없습니다.
- 기록 옮기기: 백업 파일 저장·불러오기, 코드 복사·붙여넣기로 폰을 바꾸거나 PC에서 이어 합니다.
- 배터리 절약(초당 30장), 느린 기기에서는 화질을 자동으로 낮춥니다.

## 파일 구성

```
index.html            화면 뼈대
css/app.css           스타일
js/app.js             물리·생물·돌봄·화면 (빌드 단계 없음)
js/data.js            생물·장식·배경·도구·업적·보상 수치
js/critters.js        거북이·개구리·우파루파·새우, 장식, 바닥 그리기
js/music.js           배경음악 생성
sw.js                 서비스워커 (오프라인 저장)
manifest.webmanifest  설치 정보
privacy.html          개인정보 처리방침
fonts/                고운돋움 (KS X 1001 한글 2,350자 부분집합, OFL)
icons/                앱 아이콘, 파비콘, 공유 이미지
scripts/smoke.mjs     Playwright 스모크 테스트
```

새 생물이나 장식의 값(가격, 속도, 설명)은 `js/data.js`만 고치면 됩니다.

## 로컬에서 실행

```sh
python3 -m http.server 8765
# http://localhost:8765 접속
```

서비스워커는 `https` 또는 `localhost`에서만 동작합니다. 폰으로 센서를 시험하려면 배포 주소(https)로 열어야 합니다. 주소 끝에 `?debug`를 붙이면 테스트용 `window.__eh`가 열립니다.

## 테스트

```sh
npm install
npm test            # 로컬 서버를 띄운 상태에서 실행
```

확인 항목: 첫 실행 안내와 보상, 상점에서 사기, 이름 바꾸기, 설정 저장, 다시 열기, 서비스워커, 오프라인 실행, 글꼴, 콘솔 오류 없음.

## 새 버전 내보내기

버전 번호가 네 곳에 있습니다. 함께 올립니다.

- `sw.js`의 `VERSION`
- `index.html`의 `css/app.css?v=`, `js/app.js?v=`
- `js/app.js`의 `VERSION`과 `import ... ?v=`

화면 문서는 네트워크를 먼저 쓰고, 나머지 파일은 버전이 붙은 주소로 저장해 둡니다. 그래서 새 버전과 옛 버전 파일이 섞이지 않습니다.

## 저장 형식

`localStorage`의 `eohangmeong.v2`에 JSON으로 저장합니다. 1.x 저장본(`eohangmeong.v1`, 물고기 한 마리)은 처음 열 때 자동으로 옮기고 업데이트 선물을 줍니다. 저장본과 불러온 백업은 열 때마다 검사해서, 모르는 생물·장식이나 망가진 값이 있어도 앱이 멈추지 않습니다.

## 브라우저 앱으로 못 하는 것

- 움직이는 배경화면(라이브 월페이퍼): 안드로이드 네이티브 앱에서만 가능합니다. 스토어 출시 때 만듭니다.
